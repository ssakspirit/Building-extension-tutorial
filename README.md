# Building Extension Tutorial

Building Extension 사용법을 배우는 튜토리얼입니다.

## 튜토리얼 시작하기

```
https://minecraft.makecode.com/#tutorial:github:ssakspirit/Building-extension-tutorial/tutorial
```

## 내용

- 직각 건물 만들기 (ㅁ, ㄱ, ㄷ형)
- 원형 건물 만들기
- 건물 지우기

## 명령어

- `1` - 작은 건물 만들기
- `2` - 큰 건물 만들기
- `0` - 직각 건물 지우기
- `3` - 원형 건물 만들기
- `00` - 원형 건물 지우기
